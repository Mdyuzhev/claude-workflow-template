# kit — комплект для внешнего участника

Публичный набор документов для тех, кто дорабатывает `<PROJECT>` **вне**
внутреннего контура команды: человек, человек с LLM-ассистентом или
автономный агент-раннер. Всё, что здесь написано, самодостаточно — не требует
доступа к внутренней инфраструктуре проекта и не предполагает знания её
устройства.

> hint: удали этот блок после первого коммита. Замени `<PROJECT>` / `<OWNER>` /
> `<PROJECT_PATH>` во всех файлах kit/ на свои значения (`grep -rn '<PROJECT'`
> покажет все места).

## Для кого

- Внешний контрибьютор-человек, открывающий PR.
- Тот же контрибьютор с LLM-ассистентом (чат, ассистент в IDE, агент) в паре.
- Автономный агент-раннер, которому передана задача на реализацию — в том
  числе ведущий цепочку внутренних эпиков (kit/RULES.md §15).

## Порядок чтения

1. **`AGENTS.md`** (корень репозитория) — точка входа для агентов: что за
   проект, как подключиться, жёсткие запреты кратко.
2. **`kit/PROJECT-MAP.md`** — карта проекта: архитектура послойно, анатомия
   типового модуля (главный практический раздел — «сделай аналогично
   существующему»), ключевые инварианты, словарь терминов, короткое резюме
   «карта за минуту». Читать целиком при первом входе в задачу; резюме —
   каждой следующей сессии.
3. **`kit/RULES.md`** — полный канон правил и гейтов, каждое правило —
   с обоснованием (почему оно есть, каким дефектом выведено).
4. **`kit/PARALLEL-LINES.md`** — резервации и швы для параллельных линий
   разработки (номера задач, тестовые идентификаторы) — читать перед задачей,
   если рядом растёт вторая линия.
5. **`kit/STAND.md`** — рецепт своего локального стенда от чистой машины до
   первого зелёного прогона, включая запасной путь на случай недоступного
   общего стенда.
6. **`kit/TEST-RUNNER.md`** — прогон тестов через предпочитаемую командой
   обёртку (D-NN, kit/RULES.md §3).
7. **`kit/skills/*/SKILL.md`** — пошаговые скиллы цикла: взять задачу →
   развернуть окружение → сделать и прогнать гейты → оформить PR.
8. **`kit/PR-TEMPLATE.md`** — шаблон описания PR с доказательствами.

## Связь с CONTRIBUTING.md и AGENTS.md

`CONTRIBUTING.md` и `AGENTS.md` (корень репозитория, копии из
`kit/templates/`) — короткие точки входа: для человека и для агента
соответственно. Модель веток/PR, минимальные гейты, куда писать вопросы —
там же кратко, с указателем сюда за деталями. kit — развёрнутая версия тех же
правил с обоснованиями и рецептом стенда. Правило, актуальное и людям, и
агентам, живёт в `kit/RULES.md` одним каноном — оба корневых файла на него
ссылаются, а не дублируют текст.
