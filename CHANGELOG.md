# Changelog

## 2026-09 — обновление до текущей практики

Добавлено:

- Автономный цикл эпика с единственным внешним стопом — приёмкой владельца — вместо цепочки
  подтверждений между каждой волной; канон в `.claude/PIPELINE.md`.
- `.claude/RULES.md` — жёсткие пределы (R1-R10) отдельно от операционных механик `WORKFLOW.md`.
- Явное разделение ролей: оркестратор на Opus в Claude Code, субагенты — только с явно заданной
  моделью (по умолчанию Sonnet), без исключений на дефолт инструмента.
- Канон целостности гейтов и доказательств: позитивный контроль на каждом автоматическом гейте,
  факт подтверждается закоммиченным транскриптом, а не числом в отчёте; фиксированный формат
  отчёта владельцу.
- Приёмка владельца по реальному пользовательскому пути, FINAL по явному GO, post-hoc verify
  техлида после FINAL.
- Внешние контуры исполнения: передача многозвенного эпика не-Claude модели в agent CLI,
  карточки/progress/decisions как механика цепочки, приёмка результата раундами (r1, r2 …).
- Поезда слияния и параллельные линии разработки: резервация номеров, аддитивные швы, порядок
  готовности вместо порядка старта.
- Канон базы знаний и диеты контекста: один канонический дом на факт, инверсия «указатель вместо
  копии», ротация уроков.
- `kit/` — комплект для внешнего участника (правила, карта проекта, стенд, прогон тестов через
  MCP, PR-шаблон, режим цепочки, четыре скилла).
- `mcp/` — сквозные правила дизайна MCP-серверов проекта и семь спецификаций (тест-раннер,
  конвейер закрытия, база знаний, конвейер документов, agent-driver, notify-мост, инфра-MCP).
- Агент-facing шаблоны переведены на английский (языковая политика — `.claude/PIPELINE.md` §0.5).

Убрано/отменено:

- Обязательные подтверждения владельца между каждой волной.
- Обязательный ручной визуальный smoke внутри UI-волны как отдельный шаг цикла.
- Внешний аудит-рой как обязательный шаг — вместо него self-audit A-G внутри самого цикла.
